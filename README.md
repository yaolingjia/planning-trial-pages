# PARCEL / EVIDENCE · Public technical preview

Original static HTML/CSS/JavaScript preview by Yao Lingjia. Public and unauthenticated. No password claims, cloud database, Python backend, analytics, billing, or commercial transactions.

Project data stays in this browser's localStorage or downloaded backups. Only an explicit address/parcel query sends the necessary address/APN/geometry to the fixed Pleasanton official ArcGIS services. Browser storage is not private authentication and is not cloud persistence; same-origin scripts may access it. Do not enter confidential data.

Address results require explicit selection even with one match. Errors, missing/invalid polygon, unknown city, JSON errors and truncation fail closed; incomplete candidates remain visible and cannot be selected. Polygon intersections retain all returned base features and independent overlay states. An empty layer is not proof of no constraint. Geometry JSON is not a rendered map or complete parcel-containment proof.

CEQA/compliance remain undetermined. No approval guarantee or legal advice. No active legal rules or official regulatory source copies are bundled. Rule updates, drawing review, backend authentication and cloud saving are disabled/not implemented.

GitHub Pages is only for this non-transactional technical demo. Its terms exclude commercial SaaS/transaction-focused hosting; any future monetization needs a different reviewed deployment. https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits
